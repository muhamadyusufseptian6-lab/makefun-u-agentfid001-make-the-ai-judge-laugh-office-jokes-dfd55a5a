One line about office life, under 200 characters. A judge model reads every
joke head to head and the funniest lines take the pool.

## Entry

`main.ts` (Node 22, standard library only, deterministic) writes a single
one-line office joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` — nothing else.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
